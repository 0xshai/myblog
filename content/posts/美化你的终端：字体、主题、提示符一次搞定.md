默认终端能用，但不好看。一个美化过的终端不只是颜值问题——清晰的提示符显示 Git 分支、语法高亮实时报错、历史命令自动补全，都能减少实际操作失误。

本文覆盖 Windows 和 macOS，选你的系统跟着做就行。

---

## 一、安装终端

### Windows：使用 Windows Terminal

Windows 11 已预装 Windows Terminal，在开始菜单搜索 `Terminal` 即可找到。

Windows 10 若没有，可以在微软商店搜索 `Windows Terminal` 安装。

后续所有操作都在 Windows Terminal 里进行，不要用旧的 `cmd`。

### macOS：使用自带 Terminal 或安装 iTerm2

系统自带的 Terminal 可以直接用。想要更多功能（分屏、多标签、更好的配色支持），可以装 iTerm2：

👉 https://iterm2.com/

下载 `.zip` 解压，把 `iTerm2.app` 拖进 `应用程序` 文件夹即可。

## 二、Windows：升级 PowerShell

Windows 自带的 PowerShell 版本较旧（5.x），建议升级到最新版（7.x），速度更快，功能更完整。

在 Windows Terminal 里执行：

```powershell
winget install Microsoft.PowerShell
```

安装完后，打开 Windows Terminal 设置 → 启动 → 默认配置文件，切换为 **PowerShell**（不是"Windows PowerShell"，注意区分）。

验证版本：

```powershell
$PSVersionTable.PSVersion
```

显示 `7.x` 即为新版。

## 三、Windows：安装 Oh My Posh（可选）

Oh My Posh 是 Windows 上最主流的终端美化框架，可以为提示符添加 Git 状态、时间、内存占用等信息。不需要的话跳过这节，直接看字体安装。

### 安装

直接去 GitHub 下载 exe 文件：

👉 https://github.com/JanDeDobbeleer/oh-my-posh/releases/latest

找 `install-amd64.exe` 下载。

> AMD64 是 64 位 x86 架构的通用叫法，Intel 和 AMD 处理器都适用，和品牌无关。不确定的话在终端执行 `echo $env:PROCESSOR_ARCHITECTURE`，输出 `AMD64` 就下 amd64，输出 `ARM64` 就下 arm64。

下载后**不要双击**，在终端里执行以下命令，把它移到固定位置并加入 PATH：

```powershell
New-Item -ItemType Directory -Force -Path "C:\tools"
Copy-Item "$env:USERPROFILE\Downloads\install-amd64.exe" "C:\tools\oh-my-posh.exe"
$oldPath = [Environment]::GetEnvironmentVariable("PATH", "User")
[Environment]::SetEnvironmentVariable("PATH", "C:\tools;" + $oldPath, "User")
```

重启终端，验证：

```powershell
where.exe oh-my-posh
oh-my-posh version
```

输出路径为 `C:\tools\oh-my-posh.exe` 且有版本号即为成功。

### 配置启动文件

编辑 PowerShell 的配置文件：

```powershell
notepad $PROFILE
```

如果提示文件不存在，先创建：

```powershell
New-Item -Path $PROFILE -ItemType File -Force
```

再执行 `notepad $PROFILE` 打开，加入这一行：

```powershell
oh-my-posh init pwsh --config "https://raw.githubusercontent.com/JanDeDobbeleer/oh-my-posh/main/themes/tokyo.omp.json" | Invoke-Expression
```

保存，重启终端，提示符立刻变化。

> 主题直接从 GitHub 远程加载。如果启动速度变慢，可以把主题文件下载到本地再加载：
> ```powershell
> Invoke-WebRequest "https://raw.githubusercontent.com/JanDeDobbeleer/oh-my-posh/main/themes/tokyo.omp.json" -OutFile "$env:USERPROFILE\.oh-my-posh-theme.json"
> ```
> 然后把 `$PROFILE` 里的 URL 换成 `"$env:USERPROFILE\.oh-my-posh-theme.json"`。

### 切换主题

去官网选主题，有截图预览：
👉 https://ohmyposh.dev/docs/themes

几个值得试的：

| 主题名 | 风格 |
|--------|------|
| `tokyo` | 深蓝紫，简洁 |
| `catppuccin` | 暖色调，柔和 |
| `agnoster` | 经典箭头风格 |
| `pure` | 极简，干净 |

执行以下命令打开配置文件：

```powershell
notepad $PROFILE
```

把 URL 里的 `tokyo` 换成主题名，保存重启生效。

### 取消使用 Oh My Posh

不想用了，打开配置文件：

```powershell
notepad $PROFILE
```

把 oh-my-posh 那行注释掉或直接删除：

```powershell
# oh-my-posh init pwsh --config "..." | Invoke-Expression
```

保存，重启终端，恢复默认提示符。如果想彻底删除，把 `C:\tools\oh-my-posh.exe` 删掉，再从用户 PATH 里移除 `C:\tools` 即可。

## 四、安装 Nerd Font 字体

终端主题依赖图标字体，不装会显示乱码方块。

### Windows：手动下载安装

Oh My Posh 提供了终端内安装字体的命令，但国内访问 GitHub 经常超时。直接手动下载更稳：

👉 https://github.com/ryanoasis/nerd-fonts/releases/download/v3.4.0/JetBrainsMono.zip

下载完解压，全选 `.ttf` 文件 → 右键 → 为所有用户安装。

### macOS：用 Homebrew 安装

```bash
brew install --cask font-jetbrains-mono-nerd-font
```

如果还没装 Homebrew，先执行：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

### 在终端里启用字体

字体装好后，在终端设置里切换：

| 终端 | 设置路径 |
|------|----------|
| Windows Terminal | 设置 → 配置文件 → PowerShell → 外观 → 字体 |
| iTerm2 | Preferences → Profiles → Text → Font |
| VS Code 内置终端 | `settings.json` → `terminal.integrated.fontFamily` |

统一填入 `JetBrainsMono Nerd Font`，保存重启，图标显示正常。

## 五、macOS：Oh My Zsh + Starship

### 安装 Oh My Zsh

macOS 默认已经是 Zsh，不需要额外安装 Shell。直接执行：

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

安装完会自动生成 `~/.zshrc` 配置文件，终端重启后生效。

### 安装两个必备插件

**语法高亮**（命令打错立刻变红）：

```bash
git clone https://github.com/zsh-users/zsh-syntax-highlighting.git \
  ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting
```

**自动补全**（灰色提示历史命令，按 `→` 接受）：

```bash
git clone https://github.com/zsh-users/zsh-autosuggestions \
  ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions
```

打开 `~/.zshrc`，找到 `plugins=` 这行，改成：

```
plugins=(git zsh-syntax-highlighting zsh-autosuggestions)
```

保存，执行：

```bash
source ~/.zshrc
```

### 安装 Starship 提示符

Oh My Zsh 自带主题，但 Starship 更快、信息更丰富，会自动显示 Git 分支、命令执行耗时、语言版本等。

```bash
curl -sS https://starship.rs/install.sh | sh
```

在 `~/.zshrc` 末尾加一行：

```bash
eval "$(starship init zsh)"
```

再次执行 `source ~/.zshrc`，提示符立刻变了。

## 六、配色方案

提示符改好之后，终端的背景和文字颜色也值得换一换。这些配色方案系统默认没有，需要手动导入。

几个经典配色：

| 配色方案 | 风格 | 适合 |
|----------|------|------|
| Tokyo Night | 深蓝紫，对比柔和 | 长时间写代码 |
| Catppuccin Mocha | 暖棕，配色协调 | 喜欢暖色调 |
| Dracula | 高对比，颜色鲜明 | 白天光线强 |
| One Dark | 经典，VS Code 同款 | 和编辑器保持一致 |

### Windows Terminal

去这个网站挑选，找到喜欢的点 `Get theme`，会复制一段 JSON：

👉 https://windowsterminalthemes.dev/

然后打开 Windows Terminal 的 `settings.json`：

```
设置 → 左下角点「打开 JSON 文件」
```

找到 `"schemes": [` 这一行，把复制的 JSON 粘贴进数组里，保存。

最后在设置里启用：

```
设置 → 配置文件 → PowerShell → 外观 → 配色方案
```

下拉选择刚导入的名字即可。

### iTerm2

在 `Preferences → Profiles → Colors → Color Presets → Import` 导入 `.itermcolors` 文件。

各配色方案的 `.itermcolors` 文件可以在对应 GitHub 仓库找到，比如 Dracula：
👉 https://draculatheme.com/iterm

## 七、可选：背景透明效果

不喜欢纯色背景，可以开启透明效果。

**Windows Terminal**，在设置里直接调：

```
设置 → 配置文件 → PowerShell → 外观 → Transparency
→ Background opacity 拖到 85% - 95%
```


**iTerm2** 在 `Preferences → Profiles → Window → Transparency` 拖动滑块，勾选 Blur 开启模糊。

透明度不建议调太高，字看不清反而影响使用。

## 小结

| | Windows | macOS |
|---|---------|-------|
| 终端 | Windows Terminal | iTerm2 / 自带 Terminal |
| Shell | PowerShell 7 | Zsh（系统自带）|
| 美化框架 | Oh My Posh | Oh My Zsh + Starship |
| 语法高亮 | 框架内置 | zsh-syntax-highlighting |
| 自动补全 | 框架内置 | zsh-autosuggestions |
| 字体 | JetBrainsMono Nerd Font | 同左 |

整个流程大概 20 分钟，配好之后基本不需要再动。
下次打开终端，至少不会再盯着一个黑框发呆了。
