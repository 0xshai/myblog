## 它解决了什么问题

用了多年笔记软件，很多人都卡在同一个问题上：

- **Notion**：界面漂亮、协作强，但数据在服务器上，断网就瘫，免费版有限制
- **Obsidian**：本地存储、插件丰富，但编辑体验原始，上手门槛不低
- **Evernote / Bear**：易用，但格式私有，迁移麻烦，长期订阅费用累积可观

Tolaria 的出发点很简单：**把 Obsidian 的数据主权 + Notion 的编辑体验 + AI 原生集成，合三为一。**

## 核心设计理念

### 🗂 文件优先，不是数据库

每一条笔记都是一个 `.md` 文件，存在你的硬盘上。没有私有数据库，没有加密格式，任何文本编辑器都能打开。即使 Tolaria 明天停止开发，你的笔记也完好无损。

### 🔁 Git 就是你的同步和备份

每个笔记库（vault）本身就是一个 Git 仓库。你可以：

- 把它推送到 GitHub / Gitea 私有仓库免费同步
- 查看任意一条笔记的完整修改历史
- 随时回滚到任意历史版本

不需要订阅 Tolaria 的云服务，不需要相信任何第三方。

### 🤖 AI 不是插件，是基础设施

Tolaria 从设计之初就把 AI 集成作为核心功能，而不是事后加上去的插件。它内置了 MCP（Model Context Protocol）服务器，让 AI 工具可以像操作文件系统一样读写你的笔记。

## 功能详解

### 编辑器

| 功能 | 说明 |
|------|------|
| 块编辑 | 类 Notion 的斜杠命令，输入 `/` 插入标题、列表、代码块等 |
| 双向链接 | `[[笔记名]]` 语法，自动补全，构建知识网络 |
| 拖拽图片 | 直接拖入图片，自动保存到 vault 目录 |
| 键盘优先 | 大量快捷键，重度用户几乎不需要鼠标 |
| 所见即所得 | Markdown 实时渲染，不用在源码和预览间切换 |

### 笔记组织

Tolaria 用**类型（Type）**作为笔记的分类维度，类似轻量级数据库的"表"概念，但更灵活——类型只是导航标签，不强制校验字段。

你可以自定义类型，比如：

```
📝 日记
📚 读书笔记  
💡 想法
🔧 项目文档
```

配合**自定义视图**，按类型、标签、日期等条件筛选，保存为固定视图，随时一键切换。

### Git 版本控制

```
vault/
├── .git/           ← 完整 Git 历史
├── 日记/
│   └── 2026-06-07.md
├── 读书笔记/
│   └── 深度工作.md
└── AGENTS          ← AI 上下文配置文件
```

在 Tolaria 界面内即可完成提交、推送、查看历史，不需要打开终端。

## AI 集成方案

Tolaria 提供三种 AI 接入方式，根据自己的情况选择：

### 方案一：Claude Code（功能最强）

通过内置 MCP 服务器连接 Claude Code CLI，AI 可以：

- 读取整个 vault 的目录结构
- 搜索、创建、编辑任意笔记
- 理解笔记之间的关联

适合开发者，需要额外安装 Claude Code。

### 方案二：API 模型（最灵活）

在设置 → API 模型里配置，支持：

- **Anthropic Claude**：`https://api.anthropic.com/v1`
- **OpenRouter**：可接入多个免费模型，如 Gemini、Llama
- **阿里云百炼 Qwen**：国内直连，新用户有大量免费额度
- **DeepSeek**：`https://api.deepseek.com/v1`

### 方案三：本地模型（完全免费）

通过 Ollama 在本机运行模型，推荐：

```
ollama pull qwen2.5:7b    # 4.7GB，中文效果好
ollama pull qwen2.5:14b   # 9GB，能力更强
```

Tolaria 检测到 Ollama 运行后可自动连接，完全离线，无需任何费用。

### 方案四：手动配合（最简单）

不配置任何 AI，直接把笔记内容复制到 claude.ai 或其他在线工具处理，再把结果粘贴回来。**对于普通用户来说，这往往是最实用的方式。**

## 适合谁用

**✅ 非常适合**

- 在意数据主权、不想被云服务绑定的用户
- 有 Git 基础、希望笔记也有版本控制的开发者
- 想把 AI 深度融入知识管理工作流的人
- 管理大量 Markdown 文件的内容创作者

**⚠️ 暂时不适合**

- 需要手机随时记录的用户（移动端尚未推出）
- 依赖 Obsidian 插件生态的重度用户
- 完全不熟悉 Markdown 的新手

## 如何开始

**第一步：下载安装**

前往官网 [tolaria.md](https://tolaria.md) 或 GitHub 仓库 `refactoringhq/tolaria` 下载对应平台安装包。

**第二步：创建或打开 vault**

首次启动时，可以选择克隆官方「入门 vault」，包含完整的功能介绍和使用示例，建议新用户从这里开始。

**第三步：配置 AI（可选）**

根据上方「AI 集成方案」选择适合自己的方式配置，或者跳过这一步，先单纯用它来写笔记。

**第四步：迁移已有笔记**

如果你原来用 Obsidian，直接把 vault 文件夹用 Tolaria 打开即可——格式完全兼容。
